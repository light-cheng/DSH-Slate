# Slate 项目进度

位于 DeepSeek Harness 右侧栏的工作区级「项目进度」共享面板。将多会话之间的项目目标、验收标准、任务推进、测试证据与待修问题沉淀为按工作区隔离的持久视图。

- **日常会话主动汇报**：通过动态上下文同步当前工作区 `taskId` 与项目级验收标准，实质改动或测试后自动汇报，纯只读问答不触发无效刷新。
- **真实命令证据核对（完成不等于验收通过）**：核对会话实际命令行执行记录与退出码 `0`，跨会话实测通过后自动清理旧 `todo` 占位，子任务汇报也不误覆盖项目级验收标准。
- **0 token 线索、一键初始化与手动保护**：空项目直接读取本地 Git 与真实历史会话标题（过滤空白草稿），支持低消耗「快速初始化」，任何手动编辑均防覆盖并支持「恢复会话汇报」。

完整文档、界面截图、问题反馈和发布说明：https://github.com/light-cheng/DSH-Slate
